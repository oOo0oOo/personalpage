Oliver Dressler

Software engineer with a PhD from ETH Zürich. I build systems where software meets hard problems: AI for machine-checked mathematics in Lean 4, quantitative investment platforms and automated scientific instruments. These days I mostly build tools that let AI agents do real work: proving theorems in Lean, apps for ChatGPT and MCP servers.
